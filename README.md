# Navi Dash - Cyberpunk Speedometer

A modern, responsive speedometer PWA built with React, Vite, and SVG. Features GPS tracking, fuel consumption calculation, and a cyberpunk neon aesthetic.

![Try here](https://motorcycle-dashboard-eta.vercel.app/)

## Features

- 🚀 **Real-time Speed Tracking** - GPS-based speed detection
- ⛽ **Fuel Consumption** - Calculates fuel usage based on distance and efficiency
- 🎨 **Cyberpunk UI** - Neon glow effects with gradient speed arcs
- 📱 **Fully Responsive** - Works on any screen size and orientation
- 🏃 **Startup Animation** - Interactive speed sweep on launch
- 🔧 **Customizable** - Set initial fuel, odometer, and efficiency
- 📦 **PWA Ready** - Installable on mobile devices

## Tech Stack

- React 18
- Vite
- SVG for graphics
- Lucide React for icons
- Geolocation API
